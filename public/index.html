TR4KERIO

Addon Nuvio et Stremio

Configure ta clé API puis choisis l'application dans laquelle installer l'addon.

Nuvio utilise le relais HTTPS. Pour assurer sa compatibilité, Stremio utilise un relais HTTP : le passkey du tracker n'est alors pas chiffré entre l'appareil et le relais.

Ouvrir l'application

La clé API est encodée dans l'URL du manifest. Ne partage pas cette URL.
