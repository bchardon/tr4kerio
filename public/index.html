TR4KERIO

Configuration de l'addon

Configure ta clé API puis choisis le protocole utilisé pour joindre le tracker.

HTTPS est recommandé. Utilise HTTP uniquement si ton client ne parvient pas à joindre le tracker en HTTPS : le passkey n'est alors pas chiffré entre l'appareil et le relais HTTP.

Ouvrir l'application

La clé API est encodée dans l'URL du manifest. Ne partage pas cette URL.
